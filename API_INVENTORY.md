# API Inventory

> Generated from the FastAPI runtime route table plus transitive static analysis of controllers, local helpers, services, schemas, dependencies, and SQLAlchemy model usage.

## Scope and conventions

- **Application:** `Reknew Orbit API`
- **Inventory size:** **188 HTTP operations** across **23 modules**.
- Paths below are the final mounted paths, including the `/api/v1` registration prefix.
- **Read + Write** includes endpoints that primarily read but also persist audit, notification, acknowledgment, session, or access-log records.
- Table access is transitive through statically resolvable controller helpers and `app.services` calls.
- `None detected` means no SQLAlchemy model access was statically resolved; the endpoint may use files, generated content, or in-memory registries.
- Authentication in this codebase is primarily implemented through `x-user-id`, `x-user-email`, and sometimes `x-user-role` headers resolved to an employee. It is not represented as an OpenAPI OAuth2/Bearer security scheme.
